# Web Analytics

## Decision

The site uses Cloudflare Web Analytics.

Reason: the permanent domain is already served through Cloudflare, Cloudflare Web Analytics is free, cookie-free, and gives useful page-level visitor data without adding a consent banner for basic privacy-friendly measurement.

Cloudflare automatically injects the analytics beacon for `brasseriechateaudurbuy.be`. Do not add a manual beacon script to the site while automatic setup is enabled, or visits may be counted twice.

Google Analytics 4 is not configured. Use GA4 only if a later marketing requirement justifies the extra privacy/cookie review.

## Where To Read Stats

Cloudflare dashboard:

`Brasseurduchateau@gmail.com's Account` -> `Analytics` -> `Web analytics` -> `brasseriechateaudurbuy.be`.

## What It Measures

Cloudflare Web Analytics can show page views, visits, referrers, countries, browsers, devices, and top pages.

Search Console remains separate. It only shows Google Search clicks, impressions, CTR, and ranking position.
